## Overview

This reference guide covers the ASC (Accounting Standards Codification) organized by topic (100s-900s). Each standard includes:

- ✅ **Official Codification References** — Citations to the authoritative guidance
- ✅ **Plain English Interpretation** — Explanations for practical application
- ✅ **Effective Dates** — When standards apply and implementation timelines
- ✅ **Transition Guidance** — How to adopt new requirements
- ✅ **External Resources** — Links to FASB, AICPA, Big Four publications, and examples

**Last Updated:** December 2025 | Content reflects standards as of this date

> **Note:** Accounting standards change frequently. Always verify current requirements with the [FASB Codification](https://asc.fasb.org/) and qualified professionals.

## Private Company Council (PCC) Alternatives

The PCC provides **cost-saving alternatives** for private companies. These elections can reduce compliance costs while maintaining decision-useful financial information.

| Alternative | Topic | Key Benefit |
|-------------|-------|-------------|
| Goodwill Amortization | ASC 350 | Amortize over 10 years instead of annual impairment testing |
| Simplified Hedge Accounting | ASC 815 | Easier interest rate swap accounting |
| VIE Exemption | ASC 810 | Skip consolidation for common control leasing entities |
| Common Control Leases | ASC 842 | Use written lease terms for related parties |
| Customer Intangibles | ASC 805 | Subsume into goodwill in acquisitions |
| Stock Compensation | ASC 718 | Practical expedients for modifications |

## How to Use This Guide

### For Each Standard

Each standard documentation includes:

1. **Overview** — High-level summary of what the standard covers
2. **Scope** — What transactions are included/excluded
3. **Key Concepts** — Core principles and definitions
4. **Recognition & Measurement** — When and how to record transactions
5. **Disclosure Requirements** — What must be reported in financial statements
6. **Practical Examples** — Real-world scenarios with journal entries
7. **Private Company Alternatives** — Simplified options available to private companies
8. **Common Pitfalls** — Mistakes to avoid
9. **External Resources** — Links for further research

### Private Company Focus

This guide emphasizes practical application for private companies, including:

- **Private Company Council (PCC) alternatives** where available
- **Cost-benefit considerations** for smaller entities
- **Simplified approaches** permitted under GAAP
- **Common audit issues** from peer review findings

## Contributing

This is a **living, open source document** maintained by the community. We welcome contributions from CPAs, accountants, auditors, and other professionals with relevant expertise.

### How to Contribute

- **Found an error?** [Open an issue](../../issues) describing the problem
- **Have a correction?** Submit a pull request with your fix
- **Want to add content?** Fork the repo and submit a PR
- **Have expertise to share?** We'd love your input on complex topics

### Contribution Guidelines

1. **Cite authoritative sources** — Reference specific ASC sections when possible
2. **Be specific** — Include ASC paragraph references (e.g., ASC 606-10-25-1)
3. **Note exceptions** — Accounting rules often have exceptions; acknowledge them
4. **Avoid overclaiming** — Use language like "generally" or "typically" rather than absolutes
5. **Keep it practical** — Focus on application, not just theory
6. **Acknowledge limitations** — No guide can cover every situation

### Quality Standards

All contributions should:
- Be consistent with current authoritative GAAP
- Include citations to the Codification where applicable
- Acknowledge when guidance differs for public vs. private companies
- Note when professional judgment is required

**Together, we can make GAAP guidance more accessible for everyone.**
